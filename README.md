## 🌟 Overview (نظرة عامة)

Welcome to the **Smart Restaurant Menu**, a fully responsive, highly optimized, and interactive digital menu platform designed for modern restaurants and cafes. It provides a seamless ordering experience with powerful administrative controls.

مرحباً بكم في **المنيو الرقمي الذكي**، منصة رقمية تفاعلية سريعة الاستجابة ومُحسّنة خصيصاً للمطاعم والمقاهي الحديثة. توفر المنصة تجربة طلب سلسة للعملاء مع لوحة تحكم إدارية قوية.

## ✨ Key Features (الميزات الرئيسية)

- **🌍 Bilingual Support (دعم ثنائي اللغة):** Full support for English (LTR) and Arabic (RTL) out of the box. 
  *دعم كامل للغتين العربية والإنجليزية بشكل مدمج مع دعم اتجاه النصوص.*
- **🛒 Smart Cart & Checkout (سلة مشتريات ذكية):** Interactive floating cart with WhatsApp order integration.
  *سلة مشتريات عائمة تفاعلية مع إمكانية إرسال الطلبات مباشرة عبر واتساب.*
- **📱 PWA Ready (تطبيق ويب تقدمي):** Installable on mobile devices for a native app-like experience.
  *قابل للتثبيت على الهواتف الذكية ليقدم تجربة مشابهة للتطبيقات الأصلية.*
- **🛠️ Admin Panel & QR Generation (لوحة الإدارة وتوليد رموز QR):** Manage menu items, categories, themes, and generate printable QR code stands directly from the app.
  *إدارة الأطباق، الأقسام، والمظاهر، مع إمكانية توليد رموز QR جاهزة للطباعة لوضعها على الطاولات.*

## 🤖 AI & GEO (الذكاء الاصطناعي وتحسين محركات التوليد)

Our platform is engineered for the future of search, fully optimized for both traditional search engines and AI-driven generative engines.

تم تصميم منصتنا لتواكب مستقبل محركات البحث، فهي مُحسّنة بالكامل لمحركات البحث التقليدية ومحركات التوليد المعتمدة على الذكاء الاصطناعي.

- **Generative Engine Optimization (GEO):** Injects dynamic JSON-LD structured data (`SoftwareApplication` and `ProfessionalService`) allowing AI bots (ChatGPT, Gemini, Claude) to deeply understand the platform's purpose and context.
  *تحسين محركات التوليد (GEO): حقن بيانات مهيكلة ديناميكياً (JSON-LD) لتسمح لروبوتات الذكاء الاصطناعي بفهم سياق وهدف المنصة بعمق.*
- **Advanced SEO Injection:** Dynamic Meta tags, Open Graph, and Twitter Cards to guarantee perfect indexing and beautiful social media sharing.
  *تحسين متقدم لمحركات البحث (SEO): علامات وصفية ديناميكية لضمان الفهرسة المثالية والمشاركة الجذابة على وسائل التواصل الاجتماعي.*
- **AI Crawl Friendly:** Optimized `robots.txt` and `sitemap.xml` ensuring transparent and prioritized crawling by AI agents and major search engines.
  *صديق لعناكب الذكاء الاصطناعي: ملفات زحف وخريطة موقع جاهزة لتوجيه عناكب الذكاء الاصطناعي ومحركات البحث الكبرى بشكل سليم.*
- **Smart Theming & Color Generation:** AI-friendly, dynamically adaptive UI systems for colors and visual themes.
  *توليد الألوان والمظاهر الذكية: نظام واجهة مستخدم يتكيف ديناميكياً لتوليد ألوان متناسقة تناسب هوية المطعم وتدعم الوضع الليلي.*

## 🚀 Getting Started (خطوات التشغيل)

Follow these simple steps to run the project locally.
اتبع هذه الخطوات البسيطة لتشغيل المشروع على جهازك المحلي.

### Prerequisites (المتطلبات الأساسية)
- [Node.js](https://nodejs.org/) (v18 or higher)
- npm or yarn

### Installation (التثبيت)

1. **Clone the repository (استنساخ المستودع):**
   ```bash
   git clone https://github.com/your-username/smart-restaurant-menu.git
   cd smart-restaurant-menu
   ```

2. **Install dependencies (تثبيت الحزم):**
   ```bash
   npm install
   ```

3. **Run the development server (تشغيل خادم التطوير):**
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` in your browser. (افتح الرابط في متصفحك)

4. **Run Tests (تشغيل الاختبارات):**
   ```bash
   npm run test
   ```

5. **Build for Production (البناء للإنتاج):**
   ```bash
   npm run build
   ```
